# 日历工坊 · Calendar Studio

> 在线预览：<https://wang90.github.io/dalian-yingbo-calendar/>

一个可切换主题的轻量日历网页。它提供月视图、年视图、农历与节假日信息，并可以根据文字灵感生成专属配色主题。默认内置「英博冠军」球迷主题与 6 名一线队球员的比赛实拍图，庆祝大连英博夺得 2026 中超冠军。

## 功能

- 月历与年度总览视图，支持前后翻页、回到今天
- 日期选择器支持按年/月快速跳转、精确日期选择，并标出有比赛的月份
- 周一开头，显示农历日期、传统节日、固定节日与二十四节气
- 选中日期后可查看星期、ISO 周数、当年第几天与跨年倒计时
- 10 套精心调配的主题预设，包含金色加冕的「英博冠军」主题与「鬼灭之刃」和风主题
- 冠军主题包含金色冠军徽章、冠军绶带、五星标识、奖杯和飘落彩带
- 英博比赛照片墙：马莱莱、斯坦丘、朱鹏宇、毛伟杰、吕焯毅、廖锦涛 6 名球员的比赛实拍图，点击可查看高清大图
- 在月历和年历中标记 2026 赛季英博正式比赛日；已结束比赛显示比分，未开始比赛显示 VS
- 每月日历顶部增加「本月赛程」栏，可直接点击比赛查看比分和详情；英博主题下比赛信息始终可见
- 右侧球队面板增加下一场比赛实时倒计时；赛季结束后自动显示「本赛季已经无比赛了」
- 右侧新增「北看台战歌」按钮，播放网络热门大连英博助威歌《只为大连》，点击可播放/暂停
- 选中比赛日可在底部查看对阵、赛事、开球时间与比赛结果
- 接入英博队徽，并以梭鱼湾球场作为整个页面的背景，配合更浓的英博蓝环境色和蓝色玻璃日期格
- 「鬼灭之刃」主题使用墨绿/赤红配色、市松格纹、日轮刀徽标、呼吸水印和暗色玻璃日历
- 鬼灭主题内置网络动漫壁纸、整页角色背景、主题预览插画和圆形角色头像；图片只放在页面背景与侧栏，不覆盖日历格
- 支持通过 `?theme=yingbo` 或 `?theme=demon-slayer` 直达指定主题
- 输入任意场景、颜色或氛围描述，本地生成专属主题配色
- 可微调主色、背景色、圆角与深色氛围
- 主题与视图会自动保存在浏览器本地
- 响应式布局，移动端主题面板收纳为抽屉
- 支持键盘：`←` / `→` 切换，`T` 回到今天，`Esc` 关闭主题抽屉

## 运行

无需安装依赖，直接打开 `index.html` 即可。也可以从当前目录启动一个静态服务器：

```bash
cd calendar-studio
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173/>。

## 文件

- `index.html` — 页面结构
- `styles.css` — 主题变量、响应式布局与动效
- `app.js` — 日历、农历、主题生成及本地持久化逻辑
- `assets/players/` — 英博球员比赛照片与来源说明
- `assets/team/` — 英博队徽、梭鱼湾球场背景与来源说明
- `assets/demon/` — 鬼灭主题网络图片与版权来源说明
- `assets/audio/` — 北看台战歌音频与来源说明
